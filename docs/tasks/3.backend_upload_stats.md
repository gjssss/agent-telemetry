# Task 3: Backend Upload Stats

## 目标

实现业务表、上传入库、费用计算、缺失价格兜底和前端所需统计查询。

## 并行关系

可与 `3.codex_parser_incremental_history.md` 并行。

## 输入文档

- `docs/V1.md`
- `docs/TECH.md`

## 实现范围

- 创建 `session_metrics` 和 `upload_batches`。
- `session_metrics` 使用 `UNIQUE(user_id, provider, session_id)`。
- 上传请求从 Bearer token 解析 `user_id`，不信任客户端传入用户身份。
- 接收 session 聚合数据并 upsert 最新结果。
- 记录上传批次统计。
- 从 `models.json` 读取模型价格并计算费用。
- 模型价格缺失时不阻断上传和统计，记录缺失模型 id。
- 提供信息页、排行榜、个人页所需统计数据。
- 支持用户昵称更新。

## 当前任务测试与校验

- 使用临时数据库执行表初始化和基础 CRUD 测试。
- 用 `curl` 验证鉴权上传。
- 重复上传同一用户的同一 `provider + session_id`，确认只更新不新增。
- 不同用户上传同一 `provider + session_id`，确认不会互相覆盖。
- 删除某模型价格后上传，确认数据入库且返回缺失价格提示。
- 用 `curl` 验证信息页统计、排行榜、个人信息、昵称更新数据。
