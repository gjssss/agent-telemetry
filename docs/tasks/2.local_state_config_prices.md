# Task 2: Local State Config Prices

## 目标

实现 `~/.agent-metry` 本地状态文件管理，包括配置、登录凭据、模型价格表和上传历史文件的基础读写。

## 并行关系

可与 `2.database_auth_foundation.md` 并行。

## 输入文档

- `docs/V1.md`
- `docs/TECH.md`

## 实现范围

- 固定核心目录为 `~/.agent-metry`。
- 实现 `configManager` 管理 `config.json`。
- 首次 CLI 运行时创建 `config.json`，默认 `base_url` 为 `http://localhost:3000`。
- 使用配置时，如果读取不到目标字段，直接报错。
- 登录成功时写入 `auth.json`，保存 `access_token` 和 `refresh_token`。
- 首次运行 `server` 时创建 `models.json` 并写入默认模型价格表。
- 实现 `history.json` 的读写基础结构。

## 当前任务测试与校验

- 在临时 HOME 或隔离目录中运行配置相关单元测试，确认不会污染真实 `~/.agent-metry`。
- 验证首次运行会创建 `config.json` 并写入默认 `base_url`。
- 验证 `config set/get/list/remove` 的底层逻辑。
- 验证缺失必需配置字段时会报错。
- 验证 `models.json` 默认价格表可创建且包含 OpenAI / Claude 常见模型。
- 验证 `auth.json` 和 `history.json` 写入后可被重新读取。
