# Task 6: Integration Verification

## 目标

完成 V1 端到端验收，确认前序任务形成完整闭环。该任务不是替代前序测试，而是在每个任务已完成自身校验后做最终串联。

## 输入文档

- `docs/V1.md`
- `docs/TECH.md`
- `docs/tasks/*.md`

## 实现范围

- 清理或隔离测试用 `~/.agent-metry`。
- 使用 Bun 安装、构建并启动服务。
- 执行 CLI 主链路。
- 执行后端 curl 验收。
- 执行前端 agent-browser 视觉验收。

## 当前任务测试与校验

- `cli.js server` 能启动前后端一体服务。
- `cli.js config set/get/list/remove` 行为正确。
- `cli.js user create <email> <password>` 能创建用户。
- `cli.js login <email> <password>` 能写入 `auth.json`。
- `cli.js upload` 能扫描 Codex session、上传聚合数据、更新 `history.json`。
- 重复上传跳过未变化文件。
- 修改后的 session 文件重新上传。
- 使用 `curl` 验证健康检查、登录、上传、统计、排行榜和昵称更新。
- 使用 agent-browser 验证登录页、信息页、排行榜、个人页，截图保存到 `/tmp`。
- 最终说明是否存在未完成项或环境阻塞。
