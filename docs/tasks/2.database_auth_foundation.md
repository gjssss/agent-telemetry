# Task 2: Database Auth Foundation

## 目标

实现 SQLite + Drizzle + Better Auth 的后端基础，完成数据库初始化、用户创建、注册、登录和 Bearer token 鉴权能力。

## 并行关系

可与 `2.local_state_config_prices.md` 并行。

## 输入文档

- `docs/V1.md`
- `docs/TECH.md`

## 实现范围

- 使用 Bun 内置 `bun:sqlite` 和 `drizzle-orm/bun-sqlite`。
- 数据库路径固定为 `~/.agent-metry/data.db`。
- 首次运行 `server` 时创建并初始化数据库。
- 启用 `foreign_keys`、`journal_mode=WAL`、`busy_timeout`。
- 接入 Better Auth + Drizzle adapter + Bearer plugin。
- 用户昵称使用 Better Auth 用户表的 `name` 字段。
- 支持 `cli.js user create <email> <password>` 所需的用户创建能力，昵称默认等于邮箱。
- 支持前端 Register，默认开放，重复邮箱返回明确错误，注册成功自动登录。

## 当前任务测试与校验

- 使用临时数据库路径运行迁移/初始化测试，确认 `data.db` 可创建。
- 用 `curl` 验证健康检查。
- 用 `curl` 验证用户创建、注册、登录。
- 验证重复邮箱注册返回明确错误。
- 验证登录后可获得 cookie session 或 Bearer token 所需信息。
- 验证 token 无效时受保护接口返回未授权。
