# Task 1: Runtime Bun Baseline

## 目标

将项目运行基础切到 Bun，并清理模板命令语义，为后续 CLI、后端、前端实现提供统一运行环境。

## 输入文档

- `docs/V1.md`
- `docs/TECH.md`

## 实现范围

- 使用 Bun 作为 package manager 和 runtime。
- 后端使用 Hono on Bun 启动。
- 保留前端 Vite + React + TanStack Router。
- 调整根目录和各 package 的脚本，使安装、开发、构建、类型检查都能通过 Bun 执行。
- 移除或替换模板中的 `hello` / `web` 目标语义。
- 为后续 `cli.js server` 托管前端静态资源预留入口。

## 当前任务测试与校验

- 执行 `bun install`，确认依赖安装成功。
- 执行项目级 typecheck/build 命令，确认 Bun 脚本可运行。
- 启动后端最小服务，并用 `curl` 验证健康检查或最小 API 响应。
- 确认 CLI 帮助信息中不再把 `hello` / `web` 作为产品目标命令。
