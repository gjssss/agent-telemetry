# Task 4: CLI Commands

## 目标

实现 V1 的 CLI 主链路：启动服务、配置管理、用户创建、登录和增量上传。

## 并行关系

可与 `4.frontend_auth_navigation.md` 并行。

## 输入文档

- `docs/V1.md`
- `docs/TECH.md`

## 实现范围

- `cli.js server`: 启动后端，并托管前端静态资源。
- `cli.js config set/get/list/remove`: 通过 `configManager` 管理 `config.json`。
- `cli.js user create <email> <password>`: 创建用户，昵称默认等于邮箱。
- `cli.js login <email> <password>`: 登录服务端并写入 `auth.json`。
- `cli.js upload`: 使用 `auth.json` 中 token 上传 Codex session 聚合数据。
- `upload` 根据 `history.json` 执行增量上传。
- 删除模板 `hello` / `web` 命令语义。

## 当前任务测试与校验

- 执行 CLI help，确认命令列表符合 V1。
- 验证 `config set/get/list/remove` 命令行为。
- 在临时 `~/.agent-metry` 环境中验证 `user create`、`login` 写入文件。
- 未登录执行 `upload` 应失败并提示先登录。
- 准备测试 session 文件，验证首次上传会调用后端。
- 第二次上传未变化文件应跳过。
- 修改测试 session 文件后应重新上传并更新 `history.json`。
- 使用 `curl` 或后端日志确认 CLI 上传请求携带 Bearer token。
