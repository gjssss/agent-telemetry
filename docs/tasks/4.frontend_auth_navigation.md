# Task 4: Frontend Auth Navigation

## 目标

复用模板登录页和 layout，改造成 Agent Telemetry 的登录/注册入口和主导航框架。

## 并行关系

可与 `4.cli_commands.md` 并行。

## 输入文档

- `docs/V1.md`
- `docs/TECH.md`

## 实现范围

- 登录页保留邮箱和密码表单。
- 删除 Provider Auth 按钮。
- 删除 Terms / Privacy 文本。
- 新增 Register 按钮。
- Register 默认开放，昵称默认等于邮箱，注册成功自动登录。
- 重复邮箱注册显示明确错误。
- 主导航只保留：
  - 信息页
  - 排行榜
  - 个人页
- 移除模板导航项对用户的可见入口。

## 当前任务测试与校验

- 运行前端 typecheck/build。
- 使用 agent-browser 打开登录页并截图到 `/tmp`。
- 验证 Provider Auth 按钮和 Terms / Privacy 文本不存在。
- 验证 Register 成功后进入应用。
- 验证重复邮箱注册显示错误。
- 验证主导航只出现 V1 三个导航项。
