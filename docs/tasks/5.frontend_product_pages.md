# Task 5: Frontend Product Pages

## 目标

实现 V1 的三个主应用页面：信息页、排行榜、个人页。

## 输入文档

- `docs/V1.md`
- `docs/TECH.md`

## 实现范围

- 信息页 `/`：
  - 顶部 `1d / 7d / 30d / total` Tab。
  - 展示费用、Token、Agent、模型和行为计数字段。
  - 对模型价格缺失给出管理员补充提示。
- 排行榜 `/leaderboard`：
  - 顶部 `1d / 7d / 30d / total` Tab。
  - 子 Tab 为费用和 Token。
  - 表格展示用户排行。
  - 空数据时显示空白表格。
- 个人页 `/profile`：
  - 展示当前用户信息。
  - 支持编辑昵称，写入用户 `name` 字段。

## 当前任务测试与校验

- 运行前端 typecheck/build。
- 使用 mock 或本地后端数据验证 4 个时间 Tab 切换会重新请求数据。
- 验证排行榜费用 / Token 子 Tab 切换排序或主指标。
- 验证空数据时显示空白表格或空白数据区。
- 验证缺失模型价格提示能展示。
- 使用 agent-browser 验收信息页、排行榜、个人页，并截图保存到 `/tmp`。
- 验证个人页昵称编辑成功后页面显示更新。
